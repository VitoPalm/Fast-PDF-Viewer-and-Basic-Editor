# Project Documentation

This directory contains the working engineering notes for Antigravity PDF.

- [Project overview](PROJECT_OVERVIEW.md): architecture, workflows, and current
  risks.
- [Playwright diagnostics](PLAYWRIGHT_DIAGNOSTICS.md): desktop UI/UX findings,
  fixtures, and artifact locations from the July 2026 diagnostic pass.
- [Roadmap](ROADMAP.md): stabilization plan, glyph text repair roadmap,
  release work, native portability, and parallel agent ownership.
- [Versioning](VERSIONING.md): version number semantics and package/tag sync
  workflow.

Keep docs updated with code changes. Non-trivial changes should update the
roadmap, an ADR, a workflow note, or a test/fixture note.
